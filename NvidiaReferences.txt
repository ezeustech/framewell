This NVIDIA backend does not run Profile Inspector or a third-party optimizer.
The bridge loads the installed nvapi64.dll from Windows System32.
The low-latency compound mapping follows Inspector's published metadata, but is
disabled unless the driver exposes all required settings. Prefer in-game Reflex.

Scope and limitations:
- Apply writes only fixed DWORD settings in the selected executable's single-app
  profile. A full-path association is created for an unassociated executable.
- Existing shared, global, command-line and packaged-app profiles are protected.
  Moving a predefined shared association and cloning unknown compatibility bits
  is deliberately unsupported because exact restoration cannot be assured.
- No global settings, display modes, DLSS models, clocks, voltage, power limits,
  anticheat files, game binaries, in-game config files, or driver files are changed.
- Performance selects maximum texture filtering shortcuts, VSync off, maximum
  power preference, highest refresh and no driver FPS cap. It may add shimmer,
  texture softness or tearing. Quality selects high-quality filtering, disables
  filtering shortcuts, clamps negative LOD bias, turns VSync on and requests
  highest refresh/max power with no driver cap. VSync can add latency.
- Both are deterministic driver presets, not changes to in-game graphics or a
  guarantee of FPS or image quality. Both can raise GPU power use/temperatures.
- Low-latency mode is left unchanged by both presets. Prefer in-game Reflex.
- Preferences persist until Restore previous is selected. Restart the game.
- The journal preserves the first original state through repeated applications,
  including absent/inherited/predefined settings, and retains later manual edits.
- NVIDIA read-only checks passed on driver 621.14. Live writes were not performed
  during development. Fake-driver tests exercise the mutation/restore workflow.
